margin-notes is a tiny program that writes one short text to a file: a library
book with notes in its margins in two hands — one asking questions, the other
answering them in pencil, in the reader's own handwriting — and a borrowing
card that says the book has never been borrowed.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
