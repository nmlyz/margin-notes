margin-notes is a tiny program that writes one short text to a file: a grandmother's music box that plays a tune heard nowhere else — hummed once in a shop, where the woman behind the counter finishes it, unsurprised.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
