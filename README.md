margin-notes is a tiny program that writes one short text to a file: a woman on a night train at 2 a.m., her forehead against the window, watching her reflection slide over dark fields — until a farmhouse light comes on where she is sure no house stands.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
